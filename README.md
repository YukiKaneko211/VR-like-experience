# VR-like-experience

Video game features the VR-like experience using 360-degree panoramic images, mede by Unreal Engine 5. Since the project size is too big to upload here, the whole project is stored here: https://1drv.ms/f/c/cd99854cdd5e93e9/EtF5k1F9d7FLp96LJipYZKgBY-08YKSPG52w5Kyo2prMkQ?e=wjLV7a

## Used Assed
I used a lot of third party assets provided on Fab market place. Most of models and animations are not made by me. Check the list of downloaded assets in `Content` directory.

## Installation & How to Play
To play the game, you need to download the whole `Windows` directory and run `ZombieAi.exe` on Windows.
